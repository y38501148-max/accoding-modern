# 代码核查加载修复（1.24.5）

云端配套版本：`20261029-review-loading-r33`。

实测服务器本机详情约 20–40 毫秒，浏览器每次跨网请求约一秒。旧版详情、人工历史、历史运行定位和源码身份串行读取，首次历史对照约 3.6 秒；主要等待来自多次网络往返。浏览器没有缓存陈旧结论导致此次延迟。

- 列表将运行选择与筛选结果合并为一次请求，翻页和筛选仍读取最新结果。
- 工作台详情将人工历史、当前源码身份和同场对照身份一起返回；独立提交页也合并运行发现和详情。
- 当前源码和历史源码继续验证提交身份及 SHA-256；历史对照校验和 OJ 原文读取并行执行。
- 已成功校验的 OJ 源码按提交编号和哈希在面板内保存，最多 32 份，重置面板时清除。人工结论和修改历史不使用此缓存。
- 保留迟到响应隔离、草稿保护、三态协议、保存前写入鉴权及修订冲突检查。
- 云端响应增加 `Server-Timing`，便于区分服务处理与网络等待。

同一真实提交的只读临时面板验证：人工编辑区约 2.16 秒降至 0.96 秒，首次历史对照约 3.63 秒降至 1.07 秒；独立提交页约 1.36 秒。网络状态会影响实际耗时。验证使用新版源代码，未替用户安装浏览器扩展。

前端 262 项测试、相关后端 76 项测试以及浏览器请求数量、源码复用、草稿保护、迟到响应场景通过。部署逐条核对并保留 956 条人工反馈、52 个运行、27 个激活记录及 28 项采集配置。没有重新核查或导入结果。
