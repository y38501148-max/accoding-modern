# Accoding Modern

E 赛可在「教学工作台 → 比赛分析」直接导出成绩。未采集的 E 赛会先刷新 OJ 榜单，再按当前班级和“含重修学生”筛选生成 Excel；包含总分、OJ 原始名次、逐题分数与判定。“统计范围”工作表记录数据来源、读取时间和导出时间；赛后可见榜单可能包含补题成绩。已采集比赛继续使用云端成绩导出。

北航 Accoding 管理站的 Tampermonkey 用户脚本，提供界面美化、班级教学工作台、赛事统计、代码复核与题目编辑工具，沿用原站账号和权限。

[安装 / 更新脚本](https://raw.githubusercontent.com/y38501148-max/accoding-modern/main/accoding-modern.user.js) · [版本与更新记录](https://github.com/y38501148-max/accoding-modern/releases) · [问题反馈](https://github.com/y38501148-max/accoding-modern/issues)

## 安装与更新

1. 安装并启用 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 点击上方安装链接，在扩展窗口确认安装。
3. 打开或刷新 [Accoding 管理站](https://accoding.buaa.edu.cn:4000/)。

支持直连管理站、`accoding-4000.e1/e2/e3.buaa.edu.cn` VPN 入口，以及 [d.buaa.edu.cn](https://d.buaa.edu.cn/) 的 Accoding `/https-4000/…/` 代理路径。VPN 入口需先完成北航登录。代码复核使用 `muzermat.online` 数据 API，启用时请接受篡改猴的对应跨域权限。

脚本会提示新版本，也可在班级页版本号旁点击「检查更新」，或通过篡改猴检查更新。安装更新后刷新 OJ 页面。[更新记录](https://github.com/y38501148-max/accoding-modern/releases)统一放在 Releases。

## 主要功能

| 功能 | 入口与用途 |
| --- | --- |
| 界面与导航 | 整理管理页和赛时页布局，集中比赛工具，支持窄屏与返回上级页面。 |
| 跨页筛选 | 在题目、赛事、小组和评测记录列表搜索，支持加载进度、暂停、继续与重试。 |
| 班级工作台 | header「班级管理」导入 XLS / XLSX 名册，查看逐题统计、学生提交与代码，导出 XLSX / CSV 成绩。 |
| 赛事统计看板 | 从赛事列表或比赛工具打开，展示通过／尝试人数、倒计时、全屏投屏和增量动画。 |
| 补题工具 | 独立补题排行榜；已结束比赛可按原站权限一键开启补题。 |
| 代码复核与查重 | 查看规则线索、前后代码差异和同题相似代码，保存助教结论与理由，导出复核结果。 |
| 题目编辑 | Markdown 兼容预览、复制与保存；批量选择测试点并检查配对和文件重名。 |
| Statement 导出 | 比赛工具「一键导出 Statement」，按题序汇编题面、编译公式并保存为 PDF。 |
| VPN 公式 | 内置 MathJax 渲染器，修复 VPN 页面公式资源加载问题。 |

## 常用操作

**班级与成绩**：班级管理 → 名册管理 → 导入 XLS / XLSX → 预览并创建班级 → 选择比赛、读取榜单。成绩导出包含全部名册学生及逐题状态。名册保存在当前浏览器，同一脚本管理器内直连与 VPN 入口共享；首次升级后先打开原名册所在入口。不同浏览器或设备不会同步，请保留原名册。

**Markdown 编辑**：进入题目编辑页，直接粘贴普通 Markdown。已保存的 OJ 公式会还原为编辑格式，保存时处理公式反斜杠、下标、公式定界符和围栏代码；重复打开、保存不会累加转义。可用「复制通用 Markdown」「复制 OJ 格式」「查看保存格式」核对输出。代码内容和其他表单字段保持原样，保存仍由原站按钮确认。

**批量测试点**：题目编辑 → 基本设置 → 批量添加测试点 → 选择多个文件或文件夹 → 检查预览 → 填入测试点 → 原站保存。ZIP 请先解压。按同名 `.in` 与 `.ans` / `.out` 配对，追加已有列表；缺失答案、重名或冲突会阻止填入，文件夹层级不会保留。已有测试点共享文件名时会警告并阻止相关删除，已损坏的服务端记录仍需后端修复。

**Statement 导出**：在新旧比赛详情页的比赛工具中，点击「一键导出 Statement」。等待题面、公式和图片加载完成，在打印窗口选择「另存为 PDF」。按比赛题序逐题分页，默认文件名取比赛名称第一个横线之前的简称，如 `C5-Statement.pdf`；取消打印后可在预览中再次保存。仅导出当前账号有权读取的题面，题面缺失、图片或公式加载失败时停止导出。

**开启补题**：在已结束比赛的比赛工具中操作，将本组个人私有题目设为组内可见；跳过其他权限及被同组未结束比赛复用的题目。无法确认结束时间或复用情况时停止操作，完成后显示核验结果。

**恢复原版**：header「设置 → 恢复原版」（赛时页为「恢复原版外观」）；可勾选「记住不使用新版界面」。点击「启用新版界面」恢复。停用全部功能需在篡改猴中关闭脚本并刷新。

## 使用说明与边界

- [班级、提交与成绩导出](docs/class-preview.md) · [补题排行榜](docs/upsolve-preview.md) · [代码复核与查重](docs/ai-review.md)
- [测试点上传验证](docs/batch-upload-validation.md) · [重复文件问题与后端修复参考](docs/duplicate-testdata-repair.md)
- 统计依据当前账号可见榜单，每人每题计一次；权限、封榜和缓存会影响结果。跨页筛选仅在显示「全部加载完成」时代表已遍历所有分页。
- 规则命中和代码相似仅供人工核查，不等于已确认使用 AI 或抄袭。查重从 E 题开始，支持全场对照与本班筛选；人工结论、理由和修改历史保存在云端。
- 界面美化与班级统计无需独立服务器，名册不上传；代码复核与查重读取独立云端服务。公开版本检查不携带 OJ Cookie 或页面数据。
- 脚本不自动提交代码或触发重评。上传测试点、保存题面、修改补题权限及保存复核结论均由用户主动操作。

## 本地开发

需要 Node.js 18 或更高版本，无需安装第三方依赖。

```bash
npm run check    # 构建、产物语法检查与自动测试
npm run preview  # 启动隔离的本地预览
```

预览入口：[赛事列表](http://127.0.0.1:18764/contest/index)、[比赛页面](http://127.0.0.1:18764/contest-ng/index.html#/1326)、[题目编辑](http://127.0.0.1:18764/problem/100/edit)。预览使用模拟名册、榜单及提交，人工结论仅保存在当前页面。

浏览器回归入口：[工作区布局](http://127.0.0.1:18764/tests/browser-workspace.html)、[XLS / XLSX 导入](http://127.0.0.1:18764/tests/browser-class-import.html)。Markdown 编辑回归脚本为 `tests/browser-markdown.js`。

修改 `src/` 后运行 `npm run build`，不要直接编辑根目录构建产物。版本号统一维护在 `package.json`；构建生成 `accoding-modern.user.js`、`accoding-modern.meta.js` 和 `version.json`。发布前运行检查并核对本地预览。

## 逐题过题曲线

教学工作台的“比赛分析 → 逐题分析”支持在右上角选择题目，显示该题的累计过题曲线。按每位学生赛内首次 AC 统计，每分钟一个数据点、横轴每 10 分钟一个刻度；纵轴按当前题目人数自动调整。
